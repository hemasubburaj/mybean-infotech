# MyBean InfoTech website (multi-page, no build step)
Pages: index, about, service (service.html?s=seo ...), portfolio, blog, careers, contact.
Run: `python3 -m http.server 3000` in this folder, open http://localhost:3000
Edit contacts, social links, services, projects and copy at the top of script.js.
Colors/fonts: variables at the top of styles.css.
Header, menu, footer and floating WhatsApp button are injected from script.js on every page.
